# Portfolio

Portfólio pessoal de Vinicius De Marco, feito com React + Vite.

## Rodando localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build   # gera a pasta dist/
npm run preview # serve o build localmente
```

## Editando o conteúdo

Todos os textos (projetos, stack, certificações, sobre, contato) ficam em `src/data.js`.
O currículo fica em `public/arquivos/`.
